OpenDyslexic, by Abbie Gonzalez. https://opendyslexic.org

The two font files in this folder are the author's own compiled files,
unchanged, from https://github.com/antijingoist/opendyslexic (folder
"compiled", commit 1824da5c0e41dc3e13ffc7f3a636dcaf695d61b7, 2025-08-11).
They are licensed under the SIL Open Font License 1.1; the licence is
OFL.txt beside this file and travels with the fonts.

They are not subsetted, renamed or edited. "OpenDyslexic" is a Reserved
Font Name: a modified copy must not carry it.

AyahSpring offers the font as a reading setting (/account/accessibility).
A browser downloads it only for a reader who chose it, and only on a page
that has text in a language written in Latin or Cyrillic letters: the font
has no letters for Arabic, Chinese and the like, and its space is much wider
than theirs, so a page in such a language is left as it was.
